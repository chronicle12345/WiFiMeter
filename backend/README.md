# C++ 本机后端

此目录预留给 Windows/Linux 共用的 C++ 后端，目前只有职责说明，没有可执行程序或 CMake 构建目标。

后续实现时按职责组织：

- `core/`：流量累计、额度和其他跨平台业务规则。
- `storage/`：历史记录、网络设置和额度的持久化。
- `ipc/`：请求解析、响应和更新事件。
- `platform/windows/`、`platform/linux/`：各系统网络采集、身份识别和控制能力，实现共用的平台接口。

构建采用 CMake，编译产物进入仓库根目录 `build/`。Electron 主进程负责接入后端，页面不直接调用系统网络 API。进程常驻方式和通信协议在真正实现时确定；目前页面仍由示例数据模块驱动。
