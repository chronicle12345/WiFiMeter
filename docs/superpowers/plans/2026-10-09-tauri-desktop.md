# 分钟设置、双向限速与 Tauri 桌面迁移

> 使用 writing-plans 和并行代理执行。用户已授权完成实现与验证，沿用工作区已有修改。

目标：自定义起止时间支持分钟；Windows 应用上传和下载可独立限速、取消；默认桌面程序改为 Tauri，发布包不包含 Electron 或 Chromium。本轮验收与发布仅面向 Windows x64，其他平台和架构保留源码构建入口。

架构：沿用 HTML/CSS/JavaScript 界面和 C++/SQLite 采集器。Tauri 提供系统 WebView、窗口、托盘和原生对话框；独立 Node 辅助进程复用经过测试的桌面业务模块，通过逐行 JSON 与 Rust 宿主通信。随包携带 Node，用户不需要安装 Node。保留已有数据目录、备份、迁移、更新、悬浮窗和限速能力。仍需 Node 的磁盘空间，减小体积来自不再附带 Chromium。

- [x] 实现 Tauri Rust 宿主、受限 IPC 与页面桥接，提供窗口、托盘、文件对话框、程序图标和显示器信息；核对悬浮窗新增通道在页面、Node 与 Rust 白名单中一致。
- [x] 实现桌面业务进程适配层，复用关闭保存、更新和旧数据导入模块；保留 Windows 数据目录并限制页面来源及允许的通道。
- [x] 实现资源准备与 Windows x64 构建流程，包含采集器、Node、驱动和许可证，资源测试通过；默认启动和打包脚本指向 Tauri。
