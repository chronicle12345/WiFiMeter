# Tauri 体积与完整发布修正

用户已授权继续优化体积、取消便携包、移除公开 SHA256 TXT 附件，并补齐 Linux 和其他 Windows 架构。沿用当前工作区并行执行，完成验证后发布 1.3.1，保留已发布的 1.3.0 标签与源码历史。

目标：保持现有业务功能，实测减少完整 Node.js 运行时的占用；发行附件仅包含安装包。Windows x64、ia32、ARM64 各生成 NSIS；Linux x64、ARM64 各生成 deb、rpm、AppImage。内部仍逐文件校验，校验清单只存在于 CI artifact。

- [x] 读取原任务、现有架构、构建与发布脚本，确认当前 91,426,304 字节 Node.js 是最大资源。
- [x] 核对远端附件并按用户明确授权删除便携 ZIP；公开 SHA256 TXT 已在先前任务中删除。
- [x] 修改 build.cjs 默认格式与 Rust target 参数，不再生成便携 ZIP；验证资源架构与 target 一致。
- [ ] 同版本精简 Node.js 源码构建，保留业务需要的 TLS、crypto、进程与文件 API；量测精简前后体积并运行桌面单元和 WebView 集成。
- [x] 修正五个平台架构任务与发布清单，增加每个安装包实际资源和可执行文件的验证。
- [x] 更新 README 与打包说明，移除 Windows x64 专属范围和便携包下载指引；发布说明待补充实测结果。
- [ ] 执行测试、构建、代码审查与 CI，发布 1.3.1 的完整安装包集合及说明。

当前证据：打包与发布辅助脚本 23 项测试通过；actionlint 与 Linux 依赖脚本语法检查通过；独立审查发现的 Linux 资源目录、AppImage ELF 比对与运行依赖问题已修复。本机 1.3.1 Windows x64 安装包使用原完整 Node.js 时，通过 37 个资源比对和 7 组实际 WebView2 检查。精简 Node.js 正在编译，体积与最终安装包验证尚未完成。

决策：不以直接删除必要 Node.js、改用过期运行时或压缩签名二进制来减少体积。先通过官方源码裁剪未使用组件并实测，若体积目标仍需全量 Rust 迁移，明确区分实测成果与后续迁移量。
