# 数据迁移与恢复

[English](MIGRATION.md) | 简体中文

## 导入旧 Windows 文件版

先退出旧采集器，再启动新版 WiFiMeter。程序默认读取 `%LOCALAPPDATA%\WiFiMeter\data`。如果使用便携版或自定义目录，请在设置 > 数据与迁移中选择旧目录导入。目录需要包含 `state.json`，或可恢复的 `state.json.bak`。

导入不会修改原文件。写入记录前，程序会把原文件和当前数据库的备份保存到新配置目录的 `migration-backups` 中。旧采集器仍占用数据，或源数据无效时，导入会停止。

同一网络、同一日期已经有记录时，默认拒绝导入。如果自动导入与已有 SQLite 数据冲突，当前流量采集会继续，可以到设置 > 数据与迁移中手动处理。手动导入允许保留已有日期，只导入其余日期。报告会列出跳过的日期，其字节数和额度计数都不会重复累计。数据库事务保证导入不会只完成一部分。

字节数由 C++ 按精确的十进制整数解析，不经过 JavaScript 浮点转换。重复导入同一来源不会重复计算流量。成功导入后，如果源文件又有变化，WiFiMeter 会提示核对。导入旧数据不会替换已有 SQLite 配置。

网络备注、兼容的额度策略和独立额度计数会转换为新格式，原设置及缓存文件保存在迁移档案中。无法明确归属到完整日期的应用缓存会存档，并在报告中列出，不计入完整的原生应用采集历史。

原 JSON 目录保留原始记录，新采集的数据只写入 SQLite。重新运行旧版时，看到的仍是原来的记录，不包含新版随后采集的流量。

## 备份与恢复

完整备份包含网络记录、小时明细、应用历史、缺失区间、设置、额度账本和迁移档案；已有的代理配置及观测记录也会一并保存。恢复会替换当前数据，完成后保持暂停采集。输入无效时会回滚，保留原记录。只包含用量的 CSV 或 JSON 导出文件无法作为完整备份恢复。

重新安装时，请保留原来的配置目录：Windows 为 `%APPDATA%\WiFiMeter Demo`，Linux 沿用已有的 Electron 配置目录。备份和导入报告可能包含网络名、本地路径等私有信息，提交到仓库或附在公开 issue 前应先检查内容。

### WebDAV 云备份

在设置 > 云备份中填写 WebDAV 地址和凭据，选择备份内容及最近天数，测试连接后即可备份或查看远端文件。自动备份只在应用运行时执行，间隔可选每小时、每天或每周。清理时只删除当前设备超出保留份数的备份。文件名带唯一后缀，旧文件名仍可读取。

恢复云备份时，只替换备份包含的数据。有日期的数据会替换备份起始日及之后的记录，更早的记录和备份未包含的数据继续保留。备份包含应用或分钟数据时，会附带一份分钟代理权重。恢复不含这些权重的旧版所选内容备份时，会清空相应日期的权重，避免把本机权重用于另一台设备的记录。

系统设置包含后端偏好、代理配置、窗口偏好、日志记录级别和已保存的应用限制。恢复限制记录后，防火墙或限速策略不会自动生效，需要在规则页查看并设置。日志保留时间、级别和来源，支持结构化快照及旧文本导出。Windows 使用 DPAPI 保护 WebDAV 密码，Linux 将文件权限限制为仅所有者可访问；凭据不进入备份。

替换数据前，程序会校验桌面设置和日志。恢复时先暂停采集，再保存 `before-cloud-restore.json.gz`，其中包含完整后端数据、可迁移的桌面设置和日志。这份压缩还原点可以从普通文件恢复入口打开。恢复成功后，采集保持暂停。如果操作失败，程序会尝试还原之前的数据和采集状态；还原未完成时继续暂停，并提示已保留的本地还原点。

## 后端迁移接口

`importLegacy` 接受 `{ sourceId, stateJson, settingsJson?, appUsageJson?, allowInitialSettings? }`。JSON 参数保留文件原文和数字精度，允许 UTF-8 BOM；同一 `sourceId` 重复导入只返回原结果，已导入的原文发生变化时返回 `LegacySourceChanged`。`allowInitialSettings` 仅用于确认启动前不存在数据库的新配置，后端仍会检查当前数据为空且偏好未被修改。

无法映射到完整日期或明确网络的应用缓存只归档，不计入用量；已有网络设置、用量与账本不被旧缓存覆盖。导入报告保存 `settingsApplied`、转换数量和 `warnings`，可通过 `migrationStatus` 读取。完整备份保存原迁移文档、报告和网络映射；缺少新字段的旧备份保留原精度，不补造分钟数据。
