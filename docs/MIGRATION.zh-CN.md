# 数据迁移与恢复

[English](MIGRATION.md) | 简体中文

## 导入旧 Windows 文件版

先退出旧采集器，再启动新版。默认读取 `%LOCALAPPDATA%\WiFiMeter\data`；便携版或自定义目录可在设置 > 数据与迁移中使用旧目录导入功能。目录需要包含 `state.json`，或可恢复的 `state.json.bak`。

导入只读取原文件，不修改原目录。提交新记录前，程序会在新配置目录的 `migration-backups` 中保存原文及迁移前数据库备份。旧采集器占用或数据无效时会停止导入。同一网络的日期记录发生重叠时，默认拒绝导入。自动导入若遇到已有 SQLite 数据库中的日期冲突，当前流量采集会继续，冲突会保留在设置 > 数据与迁移中供手动处理。手动导入时，可以明确选择保留已有日期，只导入没有冲突的日期。报告会列出跳过的日期，这些日期的字节数与额度计数都不会重复累计。数据库事务避免只写入一半。

字节数由 C++ 按精确十进制整数解析，不经过 JavaScript 浮点转换。重复导入同一来源不会重复累计。成功导入后若原来源又有变化，会提示核对，避免再次相加。已有 SQLite 配置不会被旧目录直接覆盖。

网络备注、可转换的额度策略及独立额度账本会映射到新格式。原设置和缓存原文仍保存在迁移档案中。无法明确归属到完整日期的应用缓存会在报告中列出并保留原文，不会作为完整的原生应用采集历史展示。

原 JSON 目录只作为保留副本，新采集记录写入 SQLite，不会继续同步回旧目录。重新运行旧版时，看到的是旧目录中的记录，不包含新版随后采集的数据。

## 备份与恢复

完整备份包含网络记录、小时明细、应用历史、缺失区间、设置、额度账本和迁移档案；有代理配置及观测时也会包含它们。恢复会替换当前数据，并暂停采集。无效输入会回滚，不会只替换部分记录。只导出用量的 CSV 或 JSON 不能当作完整备份恢复。

应用保留跨平台配置目录的位置。Windows 配置目录仍为 `%APPDATA%\WiFiMeter Demo`，Linux 沿用已有的 Electron 配置目录，重新安装时请保留。备份和导入报告可能包含网络名及本地路径，属于用户私有数据，未经检查不应提交到仓库或附在公开 issue 中。

### WebDAV 云备份

在设置的云备份页填写 WebDAV 地址和凭据，选择内容与最近天数，测试连接后备份或查看远端文件。自动备份在应用运行时按所选的每小时、每天或每周间隔执行，只清理该设备超出保留份数的备份。文件名带唯一后缀，旧文件名仍可读取。

云备份替换它包含的部分。带日期的部分替换备份起始日及之后的记录，更早的记录和未包含的部分继续保留。应用或分钟部分会包含一份分钟代理权重。旧的所选备份没有这些证据时，会清空覆盖日期的权重，避免把本机权重用于另一设备的记录。

系统设置包含后端偏好、代理配置、窗口偏好、日志记录级别和已保存的应用限制记录。恢复限制记录不会应用防火墙或限速策略，可在规则页查看并设置。日志保留时间、级别和来源，支持结构化快照及旧文本导出。Windows 使用 DPAPI 保护 WebDAV 密码，Linux 使用仅本人可访问的文件权限；凭据不进入备份。

桌面和日志输入会在替换数据前校验。恢复先暂停采集，再保存 `before-cloud-restore.json.gz`，其中包含完整后端数据、桌面设置和日志；原有文件恢复入口支持该压缩还原点。恢复成功后保持暂停。操作失败时会尝试恢复原数据及采集状态；未完成的恢复保持暂停，并报告已保留的本地还原点。

## 后端迁移接口

`importLegacy` 接受 `{ sourceId, stateJson, settingsJson?, appUsageJson?, allowInitialSettings? }`。JSON 参数保留文件原文和数字精度，允许 UTF-8 BOM；同一 `sourceId` 重复导入只返回原结果，已导入的原文发生变化时返回 `LegacySourceChanged`。`allowInitialSettings` 仅用于确认启动前不存在数据库的新配置，后端仍会检查当前数据为空且偏好未被修改。

无法映射到完整日期或明确网络的应用缓存只归档，不计入用量；已有网络设置、用量与账本不被旧缓存覆盖。导入报告保存 `settingsApplied`、转换数量和 `warnings`，可通过 `migrationStatus` 读取。完整备份保存原迁移文档、报告和网络映射；缺少新字段的旧备份保留原精度，不补造分钟数据。
