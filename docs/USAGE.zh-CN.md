# 使用指南

[English](USAGE.md) | 简体中文

## 安装和打开

从仓库 Releases 下载 `WiFiMeter-Setup.exe`，按提示安装，然后从桌面或开始菜单打开。安装位置是当前用户的程序目录，不需要管理员权限。便携版使用 `WiFiMeter-Portable.zip`，解压后双击 `WiFiMeter.exe`，保留压缩包内的目录结构。两种方式都不需要打开终端。

运行要求 Windows 10/11、Windows PowerShell 5.1 和 .NET Framework 4.7.2 或更新版本。安装包尚未签名，Windows 可能显示未知发布者提示。软件和安装器默认英文，均可切换简体中文。

## 日期和网络

可选择全部累计、今天和本月。点击自选日期会弹出日历，选择开始和结束日期后应用，统计包含起止当天；取消会保留原范围。图表、表格和 CSV 导出使用同一日期范围，网络数量不设前几名限制。

卡片还可以绘制趋势：按所选范围展示已列出网络的每日下载与上传折线。范围内不足两天的数据时，折线区会显示占位提示。搜索框会随输入实时筛选网络列表，不区分大小写地匹配备注名和 SSID；汇总卡片、网络计数以及图表或表格随后只反映筛选后的网络，而 CSV 导出始终覆盖完整的所选范围。

点击网络行可打开设置和流量明细。备注只改变显示名称，不改变原始 SSID，也不合并记录。明细对话框保留原始身份：Wi-Fi SSID 原样显示，有线网卡显示保留的 `Ethernet:` 身份。当本机能够识别网卡时，网络列表和 CSV 导出会显示有线网卡的 Windows 连接名（或你为该身份设置的备注），无法识别时退回原始 `Ethernet:` 身份。Wi-Fi SSID 导出时始终保持原样。同名 SSID 合并累计，大小写不同的名称分别统计。

## 流量额度

在网络设置中填写 GB 额度，选择每日、每月或全部累计，再设置提醒百分比。额度为 0 时关闭规则，下载和上传共同计入额度。每日额度在本地时间零点重新计算，每月额度在每月 1 日重新计算。

新规则会从所选周期内保留的记录开始计算，之后的额度累计值会在重启和历史清理后保留。修改额度大小不重置累计值；修改周期会按新周期的现有记录重新计算。创建新规则时，已经删除的历史无法补回。

设置中还提供 Wi-Fi 总流量限额，把所有被统计的 Wi-Fi 网络按每日、每月或全部累计合并计算。总额不包含有线以太网流量，且与每个网络各自的限额相互独立，同一次采样中两类规则都可能触发。总额度计数器从保留的 Wi-Fi 记录初始化，之后按与单个网络相同的方式随采样累加。总限额的“达到后断开”会断开当前连接的全部 Wi-Fi 网卡，有线连接不受影响。总额度为 0 时关闭该规则。

达到提醒比例和额度上限时，托盘图标会发出通知；Windows 的通知设置可能隐藏这些提醒。达到上限后断开 Wi-Fi 默认关闭。启用后，程序会核对网卡当前仍连接指定 SSID，再执行断开。采样间隔为 5 秒，期间发生的下载可能使实际流量超过上限。超额后重新连接可能再次断开，如需继续使用，应先提高额度或关闭该规则。

## 应用流量

应用和按天两个标签页显示 Windows 提供的记录，使用当前选定的网络和日期范围。查询在后台执行，关闭明细窗口会取消未完成的查询。程序会记录实际观察到的网卡、配置文件与 SSID 对应关系；某个已断开的旧配置无法匹配时，需要在统计运行期间连接一次。

Windows 更新应用流量可能有延迟，应用合计也可能与网卡总流量不同。最多查询最近 60 天，同时不会早于 WiFiMeter 首次开始统计的时间或设置的保留期限。Windows 没有提供的记录不会补算。应用明细按需查询，不会永久归档；最近 4 次查询最多缓存 5 分钟。

经过本机代理的流量会被 Windows 记到代理进程名下。在设置中填写代理监听的 TCP 端口和代理进程名后，统计进程会记录每天有哪些程序通过代理建立连接，并在查询应用流量时按观测到的连接数占比，把代理进程名下的字节分摊到这些程序。没有观测证据的字节保留为"经代理 · 未归属"估算行。分摊结果是估算：每 5 秒采样一次连接，短连接可能漏采；UDP 和 QUIC 流量不在统计范围；Windows 的字节记录存在延迟。连接数反映活跃程度，不代表流量大小。

统计进程还会记录每个程序当前持有的连接数，并保留连接最多的程序。仪表盘的"实时应用"卡片会显示其中最多 12 个程序的连接数，每隔几秒刷新；"当日用量"视图按需查询 Windows 对当前网络今日应用流量的记录，并标注该记录可能延迟。连接数只能提示活跃程度：实时查看每个应用的字节速率需要管理员级别的 Windows 计数器，本程序不使用，因此不提供实时速率，连接数与实际流量也可能不一致，"当日用量"同样受上文应用查询的限制。当只有有线连接时，卡片会说明 Windows 不提供有线网络的应用流量记录。

## 记录保存时间

在设置中填写保留天数，今天计为 1 天，0 表示保留全部网卡统计记录。启动统计、修改设置和跨日后会自动清理，同时更新恢复副本与自动生成的 CSV。CSV 被其他程序占用时，会在占用解除后更新。

清理后，全部累计表示仍然保留的每日记录之和。当前额度累计值和网络设置继续保留，避免删除历史后额度被重置。应用查询缓存由后台维护自动清理。缩短保留期限会永久删除旧记录，仍需使用这些记录时请先备份数据目录。

## 托盘、关闭和自启动

程序运行时，Windows 右下角通知区域会出现 WiFiMeter 图标，点击可重新打开窗口。图标可能位于隐藏图标的箭头内。再次打开程序会显示已有窗口。

点击关闭会询问最小化到托盘、退出或取消。最小化后继续统计；退出会保存未写入的数据、停止统计并移除托盘图标。窗口的最小化按钮也会将程序隐藏到托盘。停止统计按钮只暂停采集，界面仍可继续使用。

开机自启动默认关闭。启用后，登录 Windows 会自动启动托盘和统计，在任务管理器的启动应用中可看到 WiFiMeter。若在任务管理器中禁用了它，需要在 Windows 启动设置中重新启用。关闭自启动不会立即停止正在运行的统计。便携版移动位置后，需要从新位置重新设置自启动。

界面与统计使用独立的 `WiFiMeter.exe` 进程，运行时看到两个进程属于正常情况。

## 数据和恢复

打开数据文件夹按钮会进入 `%LOCALAPPDATA%\WiFiMeter\data`。

| 文件 | 内容 |
| --- | --- |
| `state.json`、`state.json.bak` | 每日统计、当前额度累计值及恢复副本 |
| `settings.json` | 语言、保留时间、网络备注、额度规则和 Wi-Fi 总额度 |
| `usage.csv`、`daily.csv` | 保留记录的累计和每日导出 |
| `app-usage-profiles.json` | 已观察到的 Windows 配置文件与 SSID 对应关系 |
| `app-usage.json` | 可重新生成的应用查询缓存 |
| `proxy-clients.json` | 每天通过已配置代理观测到的去重连接 |
| 状态文件与日志 | 进程控制和错误信息 |

备份或恢复目录前先停止统计。主记录损坏时，程序尝试读取备份；两个副本都无法读取时会报错并保留文件。Excel 占用 CSV 不影响 JSON 保存，关闭 Excel 后导出文件会恢复更新。

更新和卸载均保留数据目录。通过 Windows 已安装的应用或安装目录中的 `Uninstall.exe` 卸载。卸载器会关闭该安装的程序，移除所属文件、快捷方式和启动项，并保留无关文件。

## 统计范围与排错

统计对象是本机的 Wi-Fi 与有线以太网卡，包含局域网传输和经由它们传输的 VPN 流量，不包含路由器上其他设备的流量，也不等同于运营商账单。程序从运行后开始采集，有变化时约每 10 秒保存一次。

首次采样、切换网络、计数器重置或长时间未能采样时会重新建立基准；有线网卡插拔网线同样会重建基准。无法确定归属的增量会被舍弃，切换附近可能少计；两次采样之间快速切走又切回也可能无法识别。突然断电可能丢失最近尚未保存的记录。

没有网络显示时，先检查 Wi-Fi 连接或有线网线是否插好。读写错误可查看界面提示和数据目录中的 `collector.log`、`ui.log`、`host.log`。应用明细为空时，可等待 Windows 更新记录后再查询，或查看较早的日期范围。有线连接不提供应用流量记录。
