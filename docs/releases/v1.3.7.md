# WiFiMeter v1.3.7

[English](#english) | [简体中文](#中文)

## English

This release adds WebDAV backups, expands historical proxy estimates to selected times, and refreshes the main window.

### Features and fixes

- In Settings > Cloud backup, choose what to include and how far back to go. Back up manually or schedule hourly, daily, or weekly backups while WiFiMeter is open. Each device keeps its own retention limit. You can view and restore backups from other devices.
- A cloud restore replaces the contents and dates covered by the backup. WiFiMeter pauses collection and saves a complete local restore point first. Backups can include window preferences, saved application restrictions, runtime logs, and minute proxy weights. Review restored restrictions on the Rules page before applying them. WebDAV credentials stay out of backups.
- Historical proxy estimates allocate download and upload separately using observed bytes exchanged with the proxy. When byte evidence for one direction is unavailable, estimates use connection counts for that direction. Application history and details can show estimates for custom time ranges and minute or hour groupings when matching data is available.
- The main window has a simpler application table, improved date and time filters, and charts that resize with their cards. The Rules page manages application network restrictions. The Logs page lets you filter, search, export, and clear runtime logs, and choose the recording level.
- With the application list collapsed, square and circular floating windows show the toolbar on hover or keyboard focus. You can close update notices and review the update status under Settings > About and updates.

### Installation and upgrades

This release provides one Windows x64 NSIS installer. Update from an existing Windows x64 Tauri installation, or exit WiFiMeter normally and run the attached installer. Existing data stays in `%APPDATA%\WiFiMeter Demo`. Windows x64 users of Electron 1.2.x can use this installer to migrate. Older installers for Linux and other Windows architectures are available from [Releases](https://github.com/chronicle12345/WiFiMeter/releases).

### Requirements and validation scope

Windows downloads WebView2 when it is missing. Native application capture requires system authorization. Proxy attribution depends on available observations and matching native usage. Publication requires the Windows x64 browser, backend, ETW/EStats, Rust, and packaged WebView2 checks. GitHub Actions checks the installer against its internal SHA-256 manifest and verifies the public download.

## 中文

本版新增 WebDAV 云备份，支持按所选时段查看历史代理估算，并更新了主窗口界面。

### 功能与修复

- 在设置 > 云备份中选择备份内容和历史范围。可手动备份，也可在 WiFiMeter 运行期间按小时、天或周自动备份。每台设备独立设置保留份数，可以查看和恢复其他设备的备份。
- 云备份恢复会覆盖备份所含的内容和日期。WiFiMeter 会先暂停采集，再保存一份完整的本地还原点。备份可包含窗口偏好、已保存的应用联网限制、运行日志和分钟代理权重。恢复限制记录后，可在规则页核对并应用。WebDAV 凭据不会写入备份。
- 历史代理估算按客户端与代理之间观测到的字节数分别分配下载和上传。某一方向缺少字节记录时，按连接数分配该方向的流量。存在匹配数据时，应用历史和详情可显示自定义时段及按分钟或小时分组的估算。
- 主窗口简化了应用表格，调整了日期和时间筛选，图表随卡片大小变化。规则页用于管理应用联网限制。日志页可以筛选、搜索、导出和清空运行日志，并调整记录级别。
- 应用列表收起时，方形和圆形悬浮窗在鼠标移入或键盘聚焦时显示工具栏。更新提示可以关闭，更新状态仍可在设置 > 关于更新中查看。

### 安装与升级

本版提供一个 Windows x64 NSIS 安装包。可通过现有 Windows x64 Tauri 版更新，也可正常退出 WiFiMeter 后运行发布附件中的安装包。现有数据保存在 `%APPDATA%\WiFiMeter Demo`。Windows x64 上的 Electron 1.2.x 用户可使用此安装包迁移。Linux 和其他 Windows 架构可从[版本下载页](https://github.com/chronicle12345/WiFiMeter/releases)获取旧版安装包。

### 运行要求与验证范围

Windows 在缺少 WebView2 时下载运行时。原生应用采集需要系统授权。代理归属估算取决于可用观测及匹配的原生用量。正式发布要求通过 Windows x64 浏览器、后端、ETW/EStats、Rust 和包内 WebView2 检查。GitHub Actions 使用内部 SHA-256 清单校验安装包，并验证公开下载。
