# WiFiMeter 1.2.3

## English

### Improvements and fixes

- Fixed Windows in-app updates failing during installer preparation because a detached Windows PowerShell process exited without sending its readiness signal. A detached Node helper now keeps the PowerShell installer handoff alive after the application exits. Downloads still require matching SHA-256, and the installer remains locked against replacement while waiting for the application to exit.
- Update failures identify whether downloading, SHA-256 verification, collection shutdown or the installer handoff failed, instead of combining them into one generic message.
- Moved the overview network selector into the top-right action group alongside Refresh and Export. The network quota card now fills the chart row, including when no quota is configured, with clearer spacing and an accessible setup action.
- Proxy settings explicitly accept multiple ports separated by English commas, such as `7890, 1080, 7897`. Added a format hint; duplicate ports are removed, invalid values are rejected and saved lists are preserved when reopening settings.

### Updating from earlier versions

The update fix takes effect after installing 1.2.3. Versions 1.2.1 and 1.2.2 with the affected handoff code may still fail to install this release from inside the application. Download and run the matching Windows Setup installer from this release once to upgrade. Application data is stored separately from the installation directory.

The lightweight PowerShell v1.1.1 edition retains its existing version. This release updates the Electron/native desktop edition.

## 简体中文

### 改进与修复

- 修复 Windows 应用内更新在准备安装阶段失败的问题：独立启动的 Windows PowerShell 进程会在发送就绪信号前退出。现在由独立的 Node 辅助进程维持 PowerShell 安装交接，确保应用退出后仍可启动安装程序。下载仍须通过 SHA-256 校验，等待应用退出期间锁定安装包，防止被替换。
- 更新失败提示区分下载、SHA-256 校验、停止采集和安装交接，便于定位失败原因。
- 将总览的网络选择器移至右上角，与刷新、导出按钮整齐排列。网络额度卡片填充趋势图所在行，未设置额度时也保持完整高度，调整留白并提供清晰的设置入口。
- 代理端口明确支持英文逗号分隔的多个端口，例如 `7890, 1080, 7897`。增加格式提示，自动去重，拒绝无效端口，重新打开设置后保留已保存列表。

### 从旧版本更新

更新修复在安装 1.2.3 后生效。使用旧安装交接代码的 1.2.1 和 1.2.2 仍可能无法通过应用内更新安装本版本，请先从本次发布下载并运行适合本机架构的 Windows Setup 安装包。应用数据保存在安装目录之外。

轻量 PowerShell v1.1.1 原版继续保留现有版本号。本次更新面向 Electron 与原生后端组成的桌面版。
