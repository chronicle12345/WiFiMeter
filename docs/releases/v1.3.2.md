# WiFiMeter v1.3.2

## 中文

本版修复 Windows 升级安装与应用内更新流程，并统一后续发布规范。

- 检查更新直接读取官方最新正式 Release，选择当前 Windows 架构的安装包，自动下载、核对文件长度及 SHA-256、保存数据后静默安装并重启，不再要求额外点击安装确认。
- 所有页面顶部显示下载百分比、已下载字节、校验和安装状态。失败时可直接重试；未保存的设置或无法完成的数据保存会阻止安装，保留输入，并恢复原采集状态。
- 修复旧版卸载记录指向已不存在卸载程序时的安装失败。只有安装目录、产品信息和发布者均符合 WiFiMeter 时才恢复原目录并继续安装，保留用户数据；有效卸载程序继续使用原有升级流程。
- Windows 提供 x64、x86、ARM64 安装包；Linux 提供 x64、ARM64 的 deb、rpm、AppImage，共九个安装包。Linux 继续从应用内打开官方版本页，选择适合发行版的包安装。
- 发布说明固定提供对应的中文和英文段落，缺少任一语言时 CI 阻止发布。标签发布复用同一提交已验证的五个平台产物；编译缓存与两路界面测试减少重复耗时。整套公开附件下载验证由 GitHub Actions 执行，本机仅查询元数据和检查结果。

Windows 从本版开始使用新的自动更新流程。已经安装的旧版仍需先下载本版对应架构的 `Tauri-Setup.exe` 并运行一次，才能使用修复后的更新功能。手动安装时请先正常退出 WiFiMeter。

Windows 缺少 WebView2 时仍需下载微软运行时，Linux 使用系统 WebKitGTK 4.1。Windows ARM64 的 WinDivert 下载限速仍不可用，界面继续显示各平台实际支持的能力。

公开附件只包含九个安装包，不提供便携压缩包或 SHA-256 TXT。内部校验和隔离环境中的后台测试保留，测试不操作现有用户安装或数据库。

## English

This release fixes Windows upgrade installation and in-app updates, and establishes consistent release requirements.

- Update checks read the latest official stable GitHub Release and select the installer for the current Windows architecture. The app downloads it automatically, verifies its byte length and SHA-256, saves data, then installs silently and restarts without an extra installation confirmation.
- Every page shows download percentage, downloaded bytes, verification and installation status. Failed updates can be retried directly. Unsaved settings or unsuccessful data saving block installation, preserve input and restore the original collection state.
- Installation now handles an old uninstall entry that points to a missing uninstaller. Recovery requires a matching WiFiMeter installation directory, product identity and publisher, then continues in the original directory while preserving user data. Existing uninstallers retain the original upgrade flow.
- Windows installers cover x64, x86 and ARM64. Linux x64 and ARM64 each provide deb, rpm and AppImage packages, for nine installers in total. On Linux, the app continues to open the official release page so users can install the appropriate package for their distribution.
- Release notes must contain corresponding Chinese and English sections; CI rejects publication when either is missing. Tag releases reuse verified artifacts from the same commit across all five platform targets. Compilation caches and two parallel renderer test workers reduce repeated work. GitHub Actions performs the complete public-download validation; the local machine only queries metadata and check results.

The new Windows automatic update flow starts with this version. Existing older installations need a one-time download and installation of the matching `Tauri-Setup.exe` from this release to receive the updated updater. Exit WiFiMeter normally before manual installation.

Windows still downloads Microsoft's WebView2 runtime when it is missing; Linux uses system WebKitGTK 4.1. WinDivert download limiting remains unavailable on Windows ARM64. The interface continues to report the capabilities supported on each platform.

Public assets contain only the nine installers, with no portable archives or SHA-256 TXT attachment. Internal integrity checks and isolated background tests remain; tests do not modify an existing user installation or database.
