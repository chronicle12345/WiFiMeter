# WiFiMeter 1.2.0

## 简体中文

- 增加手动检查更新和启动检查开关，显示正式版本更新说明；确认后下载匹配架构的 Windows 安装包并校验 SHA-256，Linux 打开官方下载页选择安装格式。
- 统一 README、应用和安装包 Logo；隐藏窗口暂停重绘，恢复后同步显示最新采样。

- 采用跨平台界面和 C++ 采样后端，支持 Windows 与 Linux，补回物理有线统计、中英文切换和原有 Windows 应用控制。
- 应用历史支持原生采集、按日或按月汇总、搜索及筛选导出。Windows 代理估算与原生记录分开显示，CSV 标明来源。
- 增加独立 Wi-Fi 总额度，支持每日、每月和累计周期，保留账本及提醒状态。有线流量不计入总 Wi-Fi 额度。
- 兼容旧版 JSON 数据目录。迁移前备份，事务导入，精确保留字节数，避免重复累计和覆盖已有数据；不能确定转换方式的旧缓存保留原文并给出报告。
- 完整备份覆盖小时记录、应用历史、缺失区间、额度和迁移信息；恢复失败会回滚。Windows 安装前请求旧采集器保存退出。
- 按所选日期加载历史，减少 IPC 重复扫描和大消息缓存，合并连续缺失区间，避免重复写入自启动设置。分发语言资源仅保留中英文。
- 按系统和 CPU 架构构建安装包，检查包内程序架构并实际启动验证。Windows x86 使用 Electron 43.7.7 兼容运行时，其余目标使用 44.4.5。

不同系统的采集权限和内核要求、各格式的支持范围，见[打包矩阵](https://github.com/chronicle12345/WiFiMeter/blob/v1.2.0/docs/PACKAGING-MATRIX.md)。升级前后的数据位置及保留副本见[迁移说明](https://github.com/chronicle12345/WiFiMeter/blob/v1.2.0/docs/MIGRATION.md)。

## English

- Adds manual and optional startup update checks, release notes and confirmation before downloading verified Windows updates. Linux updates open the official release page for package selection.
- Unifies README and application icons, and suspends hidden-window rendering without stopping traffic collection.

- Integrates the cross-platform interface with native C++ sampling on Windows and Linux, retaining physical Ethernet accounting, bilingual UI and Windows application controls.
- Adds daily/monthly application history and filtered export. Windows proxy estimates remain separate from native records, including explicit CSV source labels.
- Adds independent combined Wi-Fi quotas with daily, monthly and cumulative ledgers. Wired traffic is excluded, and notification state is retained.
- Imports the legacy JSON directory through a transactional, exact-integer migration with recovery backups, duplicate detection and overlap protection. Ambiguous cache entries remain archived and are reported.
- Expands complete backup/restore to hourly records, applications, coverage gaps, quotas and migration metadata. Failed restores roll back. Windows upgrades request a graceful legacy-collector shutdown.
- Reduces unnecessary history loading, repeated IPC scanning, oversized receive buffers, duplicate coverage records and autostart writes. Packages retain only English and Simplified Chinese language resources.
- Builds and verifies packages by operating system and CPU architecture. Windows x86 uses Electron 43.7.7; other targets use 44.4.5.

See the [package matrix](https://github.com/chronicle12345/WiFiMeter/blob/v1.2.0/docs/PACKAGING-MATRIX.md) for tested targets and runtime requirements, and the [migration guide](https://github.com/chronicle12345/WiFiMeter/blob/v1.2.0/docs/MIGRATION.md) for retained originals and recovery.
