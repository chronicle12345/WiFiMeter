# WiFiMeter 1.3.1

修正 1.3.0 缺少平台安装包的发布配置。Windows x64、x86、ARM64 分别提供 NSIS 安装程序，Linux x64、ARM64 分别提供 deb、rpm、AppImage。五组目标通过构建、后端、Rust 宿主和安装包验证后，才公开完整的九个附件。

取消便携压缩包。SHA-256 校验仍在 CI 内部执行，校验 TXT 不再放在 Release 下载附件中。1.3.0 的便携 ZIP 和校验 TXT 已移除。

保留 1.3.0 的分钟统计、自定义起止分钟、上传和下载独立限速、Windows 悬浮窗应用列表及时段选择。沿用原有 SQLite 用户数据目录、托盘、开机启动、备份恢复、旧数据迁移和更新功能。

Windows 安装版在缺少 WebView2 时下载运行时；Linux 使用系统 WebKitGTK 4.1。Windows ARM64 暂不支持 WinDivert 下载限速，其他平台能力以界面显示的支持状态为准。

体积优化以完整安装包测量。原 1.3.0 的最大运行资源为 91,426,304 字节 Node.js；Tauri 主程序为 3,894,784 字节，两项 C++ 采集程序合计 2,488,320 字节。原本地 NSIS 为 25,556,133 字节。精简运行时和新安装包体积将在实际构建及运行验证后补充。

本轮验证记录将以完整 CI 和本机安装包运行结果补充。下载限速吞吐、真实驱动加载和完整安装/卸载仍需目标机器验收；包内程序运行验证不等于执行安装/卸载。
