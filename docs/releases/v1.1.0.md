# WiFiMeter v1.1.0

Released on 2026-10-01. These notes cover the changes from v1.0.0 to the published v1.1.0 tag.

## English

### Added and improved

- Refreshed the light-theme interface and added a dedicated Live apps page with application search. This release shows current connection counts and a Today usage view backed by delayed Windows records.
- Added application network controls: block or restore direct network access through Windows Firewall, and apply or remove upload limits through Windows QoS. Upload limits use decimal KB/s and do not limit downloads.
- Added wired Ethernet traffic accounting. Networks display their Windows connection name or a custom alias while retaining a stable adapter identity.
- Added a total Wi-Fi quota across networks, with daily, monthly or all-time periods, percentage warnings and optional disconnection of all connected Wi-Fi adapters. Wired traffic is excluded from this total.
- Added a daily download/upload trend chart with hover details and network search by display name or SSID. The trend covers all networks in the selected range; network search filters the chart and details list.
- Added application icons and shared application-name and date filters in network details. Application totals and daily details support inclusive custom dates and background queries.
- Added estimated attribution of local-proxy traffic to client applications using observed TCP connections. Proxy setup can identify listening processes from TCP ports alone; additional process names are optional advanced settings.
- Added the MIT license.

### Fixes

- Corrected the IPv6 TCP-table row layout and excluded virtual Ethernet adapters from wired sampling.
- Refreshed today's application usage after its cached result expires and included the usage percentage in total-quota tray alerts.
- Fixed installer shortcuts for Unicode paths and corrected COM HRESULT handling.
- Improved installer diagnostics and CI execution without an interactive desktop, and added tag-triggered build, test and release automation.

### Usage notes

Application history depends on Windows records, which may be delayed and can differ from adapter totals. Proxy attribution is an estimate based on observed connections; it can miss short connections and does not cover UDP or QUIC. Windows application-history queries are not available for wired networks.

Application network controls request administrator approval. Local proxy traffic may bypass an application's rules. Firewall and QoS rules persist after exit or restart and may remain after uninstall; remove them before uninstalling if they are no longer needed.

The installer and portable build require Windows 10 or 11, Windows PowerShell 5.1 and .NET Framework 4.7.2 or later. The installer is unsigned. Updates and uninstall preserve the local data folder.

## 简体中文

### 新增与改进

- 更新浅色界面，新增独立的实时应用页面，支持应用搜索。本版本显示当前连接数，以及基于 Windows 延迟记录的当日用量。
- 新增应用网络控制：通过 Windows 防火墙禁止或恢复直接联网，通过 Windows QoS 设置或取消上传限速。限速单位为 KB/s（1000 字节/秒），不限制下载。
- 新增有线以太网流量统计。网络显示 Windows 连接名称或自定义备注，并保留稳定的网卡标识。
- 新增跨网络的 Wi-Fi 总额度，支持每日、每月或全部累计周期、百分比提醒，以及达到额度后断开全部已连接 Wi-Fi 网卡。有线流量不计入该总额。
- 新增每日下载与上传趋势图，支持悬停查看明细，并可按备注名或 SSID 搜索网络。趋势统计所选范围内的全部网络，网络搜索筛选图表和明细列表。
- 网络详情新增应用图标，以及共用的应用名称和日期筛选。应用合计和每日明细支持包含起止当天的自选日期，查询在后台执行。
- 新增本地代理流量归属估算，按观测到的 TCP 连接分摊到客户端应用。只填写代理监听端口即可识别进程，额外进程名作为可选高级设置。
- 新增 MIT 许可证。

### 修复

- 修正 IPv6 TCP 表行结构，并从有线采样中排除虚拟以太网网卡。
- 当日应用用量缓存过期后重新查询，Wi-Fi 总额度托盘提醒补充使用百分比。
- 修复 Unicode 路径的安装快捷方式，并修正 COM HRESULT 处理。
- 改进安装诊断日志和无交互桌面环境下的 CI 执行，增加由版本标签触发的构建、测试及发布流程。

### 使用说明

应用历史依赖 Windows 记录，可能延迟，也可能与网卡统计不同。代理归属依据观测连接估算，可能漏采短连接，不覆盖 UDP 和 QUIC。有线网络不提供 Windows 应用历史查询。

应用网络控制需要管理员授权，本地代理流量可能不受应用规则控制。防火墙和 QoS 规则会在退出、重启后保留，卸载后也可能残留；不再需要时请在卸载前移除。

安装版和便携版需要 Windows 10/11、Windows PowerShell 5.1，以及 .NET Framework 4.7.2 或更新版本。安装包尚未签名，更新和卸载均保留本地数据目录。
