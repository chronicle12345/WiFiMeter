# WiFiMeter 1.3.0

本轮发布范围为 Windows x64 Tauri，产物包括 NSIS 安装版、便携 ZIP 和 SHA-256 校验文件。Linux、Windows ia32 和 Windows ARM64 不在本轮验收与发布范围内。

自定义时间范围支持本地小时和分钟，结束分钟完整包含在结果内。网络与应用历史可按分钟、小时、日期查看和导出；旧记录保持已有时间精度，新的分钟明细从升级后开始积累。切换页面和预设日期后，已选的明细分组会自动重新加载。

总览首屏保留核心指标，完整应用实时排行放在下方滚动区；应用页也显示全部已采集应用，可按下载、上传或总速度排序。

Windows 应用控制支持独立设置上传和下载速度，以及分别取消限制。上传继续使用系统 QoS；Windows x64 下载限速使用随包分发的签名 WinDivert 驱动，仅在 WiFiMeter 运行期间生效。捕获失效时会释放拦截资源并报告错误，重新设置可恢复限速；连接归属采集失效时清除旧缓存并使用系统连接快照。经独立代理进程接收的流量需限制代理程序。

悬浮窗保留全部当前连接的实时上传、下载合计速度，新增可展开的应用列表，显示各应用实时速度和时段累计用量。1 分钟表示当前日历分钟，5 分钟为当前分钟加之前 4 个分钟，1 小时为当前分钟加之前 59 个分钟；自定义支持 1 到 10080 分钟。时段自动保存，累计值按真实分钟记录汇总，并显示实际起止时分。详见[悬浮窗说明](https://github.com/chronicle12345/WiFiMeter/blob/v1.3.0/docs/FLOATING_WINDOW.md)。

桌面宿主改为 Tauri，使用系统 WebView，发行包不再携带 Electron 或 Chromium。现有界面、C++ 采集器和桌面业务继续复用，Node 辅助进程随包提供。保留托盘、系统通知、开机启动、悬浮窗、主题、导出、完整备份、旧数据导入和更新检查。

使用 Electron 1.2.x 的用户需从 [GitHub Releases](https://github.com/chronicle12345/WiFiMeter/releases) 下载 Windows x64 Tauri 安装版并运行安装。Windows 数据目录仍为 `%APPDATA%\WiFiMeter Demo`，安装后继续读取其中的 `wifimeter.db`，无需重新导入已有 SQLite 数据。新旧宿主共用数据目录锁，避免同时采集造成重复计数；升级后启动前请正常退出旧版。Tauri 后续更新选择对应的 Tauri 安装包。

分钟数据、额度账本及迁移档案均纳入完整备份。跨日和跨月采样按各分钟所属日期计入历史与额度，保持日、月和累计账本一致。退出前等待采集器保存，恢复备份后仍暂停采集。

Windows 安装版在缺少 WebView2 时下载运行时；便携版需系统已有 Microsoft Edge WebView2。便携 ZIP 解压后运行其中的 `WiFiMeter.exe`，并保留同级资源目录。发布附件名称为：

- `WiFiMeter-1.3.0-windows-x64-Tauri-Setup.exe`
- `WiFiMeter-1.3.0-windows-x64-Tauri-Portable.zip`
- `WiFiMeter-1.3.0-windows-x64-Tauri-SHA256SUMS.txt`

2026-10-10 本地验证结果：Node 单元测试 343 项通过、4 项跳过；界面回归 94 项通过、2 项跳过；C++ 测试 32 项通过、1 项跳过；Rust 宿主与新旧实例兼容测试共 12 项通过；打包与发布辅助测试 11 项通过。跳过项为 Linux 文件权限、未构建的旧 Electron 包及需要管理员令牌的 TCP EStats 检查。

安装版与便携 ZIP 分别解包，37 个运行资源逐一通过 SHA-256 比对，主程序仅允许 Tauri 包类型标记存在差异。两份解包后的程序分别通过 7 组真实 WebView2 检查，覆盖随包后端发现、页面与 IPC 权限、悬浮窗时段及设置保存、清空后恢复备份、主题与页面重载、退出后辅助进程结束及 SQLite 数据保存。

本地生成的安装包为 25,556,133 字节（25.56 MB），便携 ZIP 为 37,789,294 字节（37.79 MB）。与 1.2.3 的 Windows x64 安装包 104,424,770 字节相比，安装包减少约 75.5%。CI 重新构建的压缩大小可能略有差异，以发布附件和校验清单为准。

本轮未执行真实限速吞吐、WinDivert 驱动加载、UAC、QoS 系统策略修改及完整 NSIS 安装/卸载验收；安装包验证涵盖解包内容与解包程序运行。Linux 和其他 Windows 架构不包含在本轮验证结论内。
