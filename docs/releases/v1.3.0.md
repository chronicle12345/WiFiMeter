# WiFiMeter 1.3.0

[English](#english) | [简体中文](#中文)

## English

This release currently provides the Windows x64 Tauri installer, `WiFiMeter-1.3.0-windows-x64-Tauri-Setup.exe`, containing 25,559,541 bytes. Portable ZIP and standalone SHA-256 TXT attachments have been removed. Internal integrity validation remains in place.

Features include custom start and end minutes, minute history and export, independent upload and download limits, and a floating window with an application list and usage totals for selected time ranges. Existing records retain their original precision; new minute details accumulate after upgrading. Tray integration, startup settings, Chinese and English interfaces, themes, full backup and restore, legacy data import and update checks are retained.

Windows x64 upload limiting uses system QoS. Download limiting uses the bundled signed WinDivert driver and operates while the application is running. Traffic routed through a proxy must be limited on the proxy application. Floating-window ranges include the current minute, the last five minutes, the last hour, and a custom duration of 1 to 10080 minutes.

The application uses system WebView2 and does not bundle Electron or Chromium. The installer downloads WebView2 when it is missing. The bundled Node business process and C++ collector continue to use the existing SQLite database in `%APPDATA%\WiFiMeter Demo`. Exit the previous version normally before running Setup.exe. Existing SQLite data does not require reimporting.

The release scope is Windows x64 only. The complete Windows x64, x86 and ARM64 plus Linux x64 and ARM64 installer matrix is available in [1.3.1](https://github.com/chronicle12345/WiFiMeter/releases/tag/v1.3.1). In 1.3.0, downloading and installing updates still requires user action.

The Windows x64 installer passed release CI, 37 extracted-resource checks and seven real WebView2 integration checks covering pages, backend discovery, permissions, floating-window behavior, backup and restore, and shutdown persistence. Driver loading, limiting throughput and complete installation/uninstallation still require target-machine validation. Running extracted applications does not validate a full installation.

## 中文

当前提供 Windows x64 Tauri 安装版，公开附件为 `WiFiMeter-1.3.0-windows-x64-Tauri-Setup.exe`，大小为 25,559,541 字节。便携 ZIP 和独立 SHA-256 TXT 已移除，内部完整性校验仍保留。

支持自定义起止分钟、分钟历史与导出、上传和下载独立限速，以及带应用列表和时段累计用量的悬浮窗。旧记录保持已有时间精度，新的分钟明细从升级后开始积累。保留托盘、开机启动、中英界面、主题、完整备份恢复、旧数据导入和更新检查。

Windows x64 上传限速使用系统 QoS，下载限速使用随包签名 WinDivert 驱动，仅在应用运行期间生效。经代理程序传输的流量需要对代理程序设置限制。悬浮窗支持当前 1 分钟、最近 5 分钟、最近 1 小时及 1 至 10080 分钟的自定义范围。

使用系统 WebView2，安装包不携带 Electron 或 Chromium；缺少 WebView2 时由安装器下载运行时。随包 Node 业务进程和 C++ 采集器继续读取原有 SQLite 数据。Windows 数据目录为 `%APPDATA%\WiFiMeter Demo`。升级前正常退出旧版，运行 Setup.exe；已有 SQLite 数据无需重新导入。

此版本的发布范围仅为 Windows x64。完整的 Windows x64、x86、ARM64 和 Linux x64、ARM64 安装包已在 [1.3.1](https://github.com/chronicle12345/WiFiMeter/releases/tag/v1.3.1) 提供。1.3.0 的更新流程仍需手动触发下载和安装。

Windows x64 安装包通过发布 CI、37 项解包资源比对和 7 组真实 WebView2 集成检查，覆盖页面、后端、权限、悬浮窗、备份恢复及退出保存。真实驱动加载、限速吞吐和完整安装/卸载仍需实机验收；解包后的程序运行不等于完整安装验收。
