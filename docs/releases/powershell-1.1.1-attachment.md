# Historical PowerShell 1.1.1 attachment

[English](#english) | [简体中文](#中文)

## English

This note describes a legacy attachment used by historical Electron releases. `WiFiMeter-1.1.1-PowerShell-windows-Portable.zip` was a smaller additional download for users who wanted to keep using the Windows PowerShell edition. It was built from the fixed v1.1.1 commit `2e924647957cc631e33ae099fefb56391e86afc4` with the original build script, retaining the original contents and internal version 1.1.1.0.

The attachment was separate from the Electron edition and did not include that edition's new features or fixes. After extraction, run `WiFiMeter/WiFiMeter.exe`; Windows PowerShell 5.1 and .NET Framework are required. Usage instructions are included in the original package. The 1.1.1 / PowerShell identifier remained unchanged when the enclosing Release version changed. Current Tauri releases use the installer matrix in the [release documentation](../PACKAGING-MATRIX.md).
