# WiFiMeter 1.2.2

## English

### Improvements and fixes

- Release notes in the update page now render Markdown headings, lists, code and tables. Rendered content is sanitized with DOMPurify using an allowlist of document elements and HTTPS links; scripts, event attributes and embedded images are excluded.
- Updates show separate checking, downloading, SHA-256 verification, preparation and installer-launch phases. Downloads show received bytes and, when the response provides a valid total size, a percentage. Unknown totals use an indeterminate indicator. Downloading 100% does not mean installation is complete; subsequent installation progress appears in the installer. Progress refreshes preserve the release notes' expanded and scroll state.
- The desktop overview lets the trend chart fill the remaining viewport height while retaining natural scrolling when content needs more space.
- Windows proxy attribution can use a fresh application-capture helper snapshot to resolve a proxy executable path that the ordinary-permission backend cannot read. Resolution requires matching client and reverse proxy TCP endpoints, the proxy PID and consistent process-instance evidence. Conflicting, missing, stale or out-of-order evidence does not establish attribution; identities are not cached across sampling rounds.
- Historical proxy estimates refresh through updates to affected network/date/proxy-path groups. Each update replaces the group's cumulative estimates rather than adding them again. The interface replaces a native proxy row only when estimated download and upload totals each equal the corresponding native totals; otherwise it retains the native row. Empty groups withdraw estimates, and a date change preserves the previous day's history.

### Accounting scope and historical limits

Historical attribution remains an estimate weighted by observed connection counts, not exact measured per-client historical traffic. New identity observations are recorded for the observation day only. Current client weights are not applied to past dates. Old records without observations for their date cannot be precisely reconstructed; an identified proxy without matching daily observations remains unattributed (`proxy/unattributed`).

Original application usage and network totals are unchanged. Attribution changes the displayed allocation without rewriting the native usage ledger or adding estimated rows on top of the same proxy's original traffic. A large historical upload total alone does not establish a counting error and is not reduced or corrected by this release.

Realtime Windows TCP EStats data retains its separate loopback scope: it covers observed local TCP connections, excludes UDP/QUIC and is not added to Wi-Fi totals. It cannot be summed with historical estimates or treated as a complete daily total. Polling can miss short connections and bytes outside observation windows. Update the desktop application, backend and application-capture helper together. Administrator-level native validation of the new helper identity-resolution path remains outstanding; these notes do not claim all-platform runtime validation.

### Legacy edition

This release updates the Electron/native desktop edition. The lightweight PowerShell v1.1.1 edition remains available with its existing version unchanged. Existing migration and backup guidance continues to apply.

## 简体中文

### 改进与修复

- 更新页按 Markdown 渲染发布说明，支持标题、列表、代码和表格。渲染结果经 DOMPurify 安全清理，仅保留允许的文档元素及 HTTPS 链接，移除脚本、事件属性和嵌入图片。
- 更新流程分别显示检查、下载、SHA-256 校验、安装准备和启动安装程序的状态。下载时显示已接收字节数；响应提供有效总大小时显示百分比，否则显示不定进度。下载达到 100% 不代表安装完成，后续安装进度由安装程序显示。进度刷新保留发布说明的展开状态和滚动位置。
- 桌面总览的趋势图填充视口剩余高度，内容较多时仍可自然滚动。
- Windows 代理归属可利用应用采集 helper 的新快照，补全普通权限后端无法读取的代理程序路径。补全需要客户端与代理端反向 TCP 端点、代理 PID 以及一致的进程实例证据相互匹配；证据冲突、缺失、过期或乱序时不确认归属，不跨采样轮次缓存身份。
- 历史代理估算随受影响的网络、日期和代理完整路径分组更新。每次更新整组替换累计估算，避免重复相加。界面分别确认下载与上传估算总量等于对应原始总量后，才替换代理原始行；不相等时保留原始行。空分组撤销对应估算，跨日保留前一天的历史。

### 统计范围与历史限制

历史归属仍按已观测连接数加权估算，不是精确测得的各客户端历史流量。新增身份观测只记录在观测当日，不用今天的客户端权重分配过去日期。旧记录缺少对应日期的观测时，无法精确还原；已识别代理但缺少当日观测的流量保留为未归属（`proxy/unattributed`）。

原始应用用量和网卡总量保持不变。归属调整只改变展示中的分配，不重写原始用量记录，也不把估算行与同一代理的原始流量重复累计。历史上传量较大本身不能证明计数错误，本次发布不会据此扣减或修正历史总量。

Windows TCP EStats 实时数据继续使用独立的回环统计范围，只覆盖已观测本地 TCP 连接，不包含 UDP/QUIC，不计入 Wi-Fi 总量。实时数据不能与历史估算相加，也不能视作完整的当日总量；轮询可能遗漏短连接及观测窗口以外的字节。升级时请同时更新桌面应用、后端和应用采集 helper。新增 helper 身份补全流程仍需管理员权限下的原生联调，本说明不宣称各平台运行验收均已完成。

### 轻量原版

本次升级面向 Electron 与原生后端组成的桌面版。轻量 PowerShell v1.1.1 原版继续保留，版本号不变。已有迁移与备份指引继续适用。
