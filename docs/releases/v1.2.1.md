# WiFiMeter 1.2.1

## English

### Improvements and fixes

- Settings and quota edits save automatically, with save status, validation feedback and a retry action for failed writes.
- Added an application drawer and executable icons to make application details and network controls easier to access. Updated the overview layout and live application display.
- Proxy clients now refresh with live snapshots. On Windows, TCP EStats supplies measured download/upload rates and observed byte counts for matching IPv4/IPv6 loopback TCP connections; historical proxy attribution remains a separate connection-weight estimate.
- Fixed rates dropping to zero or spiking when the backend reads the same capture snapshot more than once. Rates use the source sample timestamps and millisecond intervals; duplicate snapshots retain the last valid rate until stale, when the measurement becomes unavailable. Update both the backend and application-capture helper together.
- Added multiple quota notification thresholds, with validation, duplicate removal and ascending ordering, while retaining compatibility with existing single-threshold settings.
- Added a compact traffic window and light, dark and system-following themes. The compact window shares speed formatting and theme resources with the main interface.
- Improved access to legacy data import and handling of legacy records. Import results and backup locations are shown in the interface; see the migration guide before moving existing data.

### Measurement scope and validation

Proxy realtime data has `source=WindowsTcpEStats` and `scope=loopback`. It measures the client side of observed local TCP connections to the proxy, not the proxy's external traffic or per-application Wi-Fi usage. These bytes are excluded from Wi-Fi totals. UDP and QUIC are outside this realtime scope. EStats requires administrator rights; first samples, permission failures and stale samples do not provide a valid rate.

Observed proxy byte counts cover currently matched, measurable connections since their sampling baselines. They are not daily totals and can decrease when connections close or the baseline resets. Polling can miss short connections, bytes sent before first observation and final bytes before disconnection. Connection discovery and byte sampling have different refresh intervals. Do not combine these measured realtime values with historical proxy estimates.

Release targets remain Windows x64, x86 and ARM64, and Linux x64 and ARM64. Build targets and automated regression coverage do not establish that native capture, installation and runtime checks have passed on every platform and architecture. The updated Windows hybrid ETW/EStats capture path still requires a complete administrator-level native acceptance run; earlier EStats observations do not replace that run. Linux native capture requires its own supported-kernel and permission checks. Consult the package matrix and Windows capture guide for validation requirements.

### Legacy edition and migration

The lightweight PowerShell v1.1.1 edition remains unchanged and retains its own version. This release updates the Electron/native desktop edition. Close the old collector before importing. Import reads the legacy JSON directory without modifying it; subsequent desktop samples are stored in SQLite and are not written back to the old edition. A complete restore replaces the current dataset and leaves collection paused; usage exports are not complete backups.

## 简体中文

### 改进与修复

- 设置和额度修改后自动保存，显示保存状态、输入校验结果，并可重试失败的写入。
- 新增应用抽屉和可执行文件图标，方便查看应用详情及网络控制；调整总览布局和实时应用展示。
- 代理客户端随实时快照刷新。Windows 使用 TCP EStats 测量匹配的 IPv4/IPv6 回环 TCP 连接，显示下载、上传速率及已观测字节数；历史代理归属继续单独按连接权重估算。
- 修复后端重复读取同一采集快照时速率归零或异常升高的问题。速率按采集源时间戳和毫秒间隔计算；重复快照暂时保留上次有效速率，过期后显示不可测量。升级时需要同时更新后端和应用采集 helper。
- 额度提醒支持多个阈值，校验输入、去除重复值并按升序排列，兼容已有单阈值设置。
- 新增流量小窗，以及浅色、深色和跟随系统的主题。小窗与主界面共用速率格式和主题资源。
- 改进旧版数据导入入口及旧记录处理，在界面显示导入结果和备份位置；迁移已有数据前请参阅迁移指南。

### 测量范围与验证状态

代理实时数据标记为 `source=WindowsTcpEStats`、`scope=loopback`，测量已观测到的本机客户端与代理之间的 TCP 连接客户端一侧。其范围不包含代理对外流量或按应用划分的 Wi-Fi 用量，回环字节不计入 Wi-Fi 总量，也不覆盖 UDP 和 QUIC。EStats 需要管理员权限；首次采样、权限失败和样本过期时无法提供有效速率。

代理已观测字节数只累计当前匹配且可测连接自采样基线以来的数据，不能当作当日总量；连接关闭或基线重置后可能下降。轮询可能遗漏短连接、首次观测前及连接关闭前的末尾字节。连接发现与字节采样的刷新间隔不同。实时实测值与历史代理估算不能合并求和。

发布目标仍为 Windows x64、x86、ARM64，以及 Linux x64、ARM64。构建目标和自动回归覆盖不能证明所有平台及架构的原生采集、安装和运行测试都已通过。更新后的 Windows ETW/EStats 混合采集流程仍需完整的管理员权限原生验收，此前的 EStats 观测不能替代该验收。Linux 原生采集也需要在支持的内核及权限环境下单独验证。验证要求见打包矩阵及 Windows 采集指南。

### 轻量原版与迁移

轻量 PowerShell v1.1.1 原版保持不变，并保留独立版本号。本次升级面向 Electron 与原生后端组成的桌面版。导入前请退出旧采集器；导入读取旧 JSON 目录，不修改原目录。新版后续采样写入 SQLite，不回写旧版。完整恢复会替换当前数据并暂停采集；用量导出不能作为完整备份。
