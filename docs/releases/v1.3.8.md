# WiFiMeter v1.3.8

[English](#english) | [简体中文](#中文)

## English

This release adds domain and connection monitoring, live traffic curves, and a customizable sampling interval.

### Features and fixes

- Connect a local Clash or Mihomo controller under Settings > Proxy. The Domain and connections page shows the controller's observed domains, destinations, applications, rules, and proxy chains. Search by domain, IP, application, rule, or node, and combine application, route, and connection-state filters. Applications with the same name remain distinguishable by their paths.
- Open a connection to inspect its routing details and observation times. Export matching session records as CSV with exact integer byte counters. The controller secret stays in the host and is excluded from page responses, logs, CSV exports, and cloud backups.
- Traffic charts use curves by default. Settings > Display retains the bar-chart option and saves the selected style. The Last 5 minutes range updates with live samples, leaves unavailable intervals blank, and labels its accumulated usage as an estimate based on measured rates.
- Set the sampling interval from 0.25 to 3600 seconds, with up to three decimal places. Settings save automatically and survive a restart. A shorter interval increases sampling frequency.
- Interrupted controller observations no longer retain stale measured speeds or imply that a remote connection has closed. Connection details continue updating when a connection leaves the selected filters. Native rates use elapsed milliseconds, and overlapping missing intervals retain accounting precision and transaction rollback behavior. Chart accessibility descriptions distinguish valid measurements, including zero, from unavailable data.
- Determine routes from the controller's original outbound identities, avoiding incorrect direct/proxy labels caused by display formatting. Chart captions and legends match the selected style, and live refreshes preserve keyboard focus on the current network's detail button.

### Installation and upgrades

This release provides one Windows x64 NSIS installer. Update from an existing Windows x64 Tauri installation, or exit WiFiMeter normally and run the attached installer. Existing data remains in `%APPDATA%\WiFiMeter Demo`. Windows x64 users of Electron 1.2.x can migrate with this installer. Linux and other Windows architectures remain paused; older installers are available from [Releases](https://github.com/chronicle12345/WiFiMeter/releases).

### Requirements and validation scope

Domain monitoring covers only connections visible to the configured local controller. The controller determines whether domain and process information is available; connections that start and end between polls can be missed. This feature does not add global native DNS capture. See [controller configuration and observation limits](../CONNECTION_MONITORING.md).

Windows downloads WebView2 when it is missing. Native application capture requires system authorization. Publication requires the active Windows browser, backend, ETW/EStats, Rust, and packaged WebView2 checks. GitHub Actions validates the installer against its internal SHA-256 manifest and verifies the public download.

## 中文

本版新增域名与连接监测、实时流量曲线，以及可自定义的采样间隔。

### 功能与修复

- 在设置 > 代理中连接本机 Clash 或 Mihomo 控制器。域名与连接页面显示控制器观测到的域名、目标地址、应用、规则和代理链。可按域名、IP、应用、规则或节点搜索，并组合使用应用、路由类型和连接状态筛选。同名应用通过程序路径区分。
- 打开连接可查看路由详情和观测时间。匹配的会话记录可导出为 CSV，字节计数保留精确整数。控制器密钥保留在宿主中，不进入页面返回值、日志、CSV 导出或云备份。
- 流量图默认使用曲线。设置 > 显示中保留柱状图选项，并保存所选样式。最近 5 分钟范围随实时采样更新，无法测量的时段留空，累计用量标明为按实测速率计算的估算值。
- 采样间隔可设为 0.25 至 3600 秒，最多保留三位小数。设置自动保存，重启后继续使用。较短间隔会增加采样频率。
- 控制器观测中断后，旧的实测速率会变为不可用，并且不会据此推断远程连接已关闭。连接不再符合筛选条件时，已打开的详情继续更新。原生速率按实际经过的毫秒计算，重叠缺失时段保留计数精度和事务回滚行为。图表无障碍描述区分有效测量、真实零值和不可用数据。
- 按控制器的原始出站身份判断路由，避免名称显示处理导致直连或代理误判。图注单位和图例与所选样式一致，实时刷新时保留当前网络详情按钮的键盘焦点。

### 安装与升级

本版提供一个 Windows x64 NSIS 安装包。可通过现有 Windows x64 Tauri 版更新，也可正常退出 WiFiMeter 后运行发布附件中的安装包。现有数据保存在 `%APPDATA%\WiFiMeter Demo`。Windows x64 上的 Electron 1.2.x 用户可使用此安装包迁移。Linux 和其他 Windows 架构的构建继续暂停，可从[版本下载页](https://github.com/chronicle12345/WiFiMeter/releases)获取旧版安装包。

### 运行要求与验证范围

域名监测仅覆盖所配置本机控制器可见的连接。域名和进程信息取决于控制器的识别能力，两次轮询之间建立又结束的连接可能遗漏。本功能没有新增全局原生 DNS 采集。配置和观测范围详见[域名与连接监听](../CONNECTION_MONITORING.zh-CN.md)。

Windows 在缺少 WebView2 时下载运行时。原生应用采集需要系统授权。正式发布要求通过当前启用的 Windows 浏览器、后端、ETW/EStats、Rust 和包内 WebView2 检查。GitHub Actions 使用内部 SHA-256 清单校验安装包，并验证公开下载。
