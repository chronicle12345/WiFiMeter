# Agent Notes scope

- Follow the [Notes conventions](README.md) and [bilingual contract](../../docs/i18n/README.md).
- Search active lifecycle/class folders before creating a record; do not add a global INDEX.md.
- Record genuine alternatives and durable reasoning. Code, tests and maintained guides own current contracts and verification details.
- Update implementation facts with code. A reversed decision gets a new linked record; archived triplets and existing seals are frozen.
- Use repository commands for validation and archiving. Personal skill defaults do not override this repository's bilingual format or commands.
