# Agent Note: 云备份恢复边界

Status: implemented

[English](2026-11-19-cloud-backup-recovery.md) | 简体中文

## 问题

可选内容备份同时涉及权威流量数据、桌面偏好和日志。只保存后端还原点无法撤回所有被替换的部分。采样或迟到的桌面写入在还原点生成后继续执行，也可能覆盖用户没有选择替换的数据。

## 决定

沿用已有的完整后端文档，由 Node 宿主明确筛选和合并各部分。分钟代理字节证据随应用或分钟数据保留。桌面偏好与日志由各自负责的模块校验并恢复，替换前先完成校验。应用限制记录作为可移植数据恢复，不执行系统策略命令；凭据在本机保存，不进入备份；WebDAV 认证会将凭据发送给已配置的服务器。

先阻止新的桌面修改，等待已接受的操作完成，暂停采集，再保存完整本地还原点。恢复成功后保持暂停；安全失败时恢复原状态，恢复未完成则保留还原点并继续暂停。原有压缩文件恢复入口可读取同一还原点。当前字段和恢复规则由[应用合约](../../../../contracts/APPLICATION_TRAFFIC.zh-CN.md#分钟代理备份证据)及[迁移指南](../../../../docs/MIGRATION.zh-CN.md#webdav-云备份)维护。

## 备选方案

**复制整个配置目录。** SQLite 状态、设备专属凭据和运行文件的恢复规则不同。明确的文档和负责模块可保留事务校验，避免复制无关的本机状态。

**只恢复后端数据。** 被替换的桌面偏好或日志将缺少撤回来源。完整还原点让用户通过一个已有文件操作完成恢复。

**重新执行已保存的联网限制。** 不同设备的权限、程序路径和策略不同。先导入记录供查看，系统策略修改仍由明确的应用控制操作完成。

## 影响

筛选和恢复复用已有的完整快照，其内存和序列化成本继续存在。恢复期间暂停采集，缺失区间沿用已有计量规则记录。未知写入失败需要补偿恢复后端和宿主文件；未完成的恢复会明确报告，不会当作成功。旧备份仍可读取，但缺少的历史字节证据无法重建。
